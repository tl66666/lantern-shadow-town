## ✨ 特色

- **手势 / 鼠标双模式**：基于 MediaPipe Hands 离线识别（WASM 本地推理，无需联网调用 API），摄像头前挥手即可游玩；也可全程鼠标操作，左下角按钮或 **I 键**随时切换。
- **凝视充能交互**：手灯光晕停在目标上约 1.5 秒即「凝神点亮」，带进度环、衰减回退与防误触容差。
- **四幕剧情视频**：每关一幕 1080p 水墨实景视频，寻宝目标藏在真实画面里逐帧标定的轨迹上。
- **灵杰角色卡**：每关寻得一位「灵杰」——显影动画 + 台词配音 + 角色详情卡。
- **幸运转盘**：四关集齐后原地转盘揭晓，灯光高亮停针、光爆星屑庆祝，抽中角色播放专属棒棒糖配音。
- **四印合璧**：集齐四印触发大结局视频与天梯上升终章配乐。
- **纯本地运行**：音频氛围全部由 WebAudio 实时合成，视频素材内置，断网也能玩。

## 🎮 玩法

灯影古镇里散落着女娲补天时遗落的**四枚神印**，由四位「灵杰」守护：

| 关卡 | 场景 | 灵杰 | 司职 |
| ---- | ---- | ---- | ---- |
| 第一关 | 灯河梦鹿（水乡元宵灯会） | 梦鹿 | 司梦 · 灯河锦囊 · 红袍鹿角 |
| 第二关 | 庙会神马（山门庙会大街） | 神马 | 司福 · 白马红袍 · 金绸额福 |
| 第三关 | 溪畔李白（桃花溪月夜） | 李白 | 司诗 · 白袍墨镜 · 醉步邀月 |
| 第四关 | 街市萌莎（字画古玩街） | 萌莎 | 司画 · 深裙金边 · 油画之姿 |

1. **寻宝**：手灯光晕扫过街景，找到本关灵杰，凝视点亮。
2. **识人**：结算屏角色卡大图显影，点卡可查看详情与专属配音。
3. **集印**：每关得一印，通关后进入下一幕。
4. **转盘**：四关全通触发幸运转盘，抽取角色棒棒糖奖励。
5. **合璧**：四印齐 → 「四印合璧」→ 大结局，灯火长明。

## 🚀 快速开始（本地版 · 流畅体验推荐）

本地版素材全部从硬盘读取：**视频秒开、不卡顿、可离线游玩**，是最完整的体验方式。

> ⚠️ **摄像头手势必须在 `localhost` 或 HTTPS 下才可用**（浏览器安全上下文要求），直接双击 `index.html` 文件无法启用手势模式。

### 下载游戏文件

- **一键下载 ZIP**（推荐）：[lantern-shadow-town-main.zip（约 120MB）](https://github.com/tl66666/lantern-shadow-town/archive/refs/heads/main.zip)，下载后解压到任意目录。
- 或使用 Git：`git clone https://github.com/tl66666/lantern-shadow-town.git`

### 启动方式一：一键启动（Windows，推荐）

双击 **`启动游戏.bat`** —— 自动调用 Node 起服务并打开浏览器，重复双击会自动检测已在运行的服务，直接打开页面。

### 启动方式二：Node 服务器（零依赖）

```bash
node serve.js              # 默认端口 8126，被占用自动 +1，就绪后自动开浏览器
PORT=9000 node serve.js    # 自定义端口
DYGZ_NO_OPEN=1 node serve.js   # 不自动打开浏览器
```

### 启动方式三：任意静态服务器

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### 首次进入

1. 允许浏览器使用摄像头（仅本地推理，画面不会上传任何服务器）。
2. 也可选择「鼠标模式」，无需摄像头即可完整体验。

## 🧱 技术栈

| 层 | 实现 |
| ---- | ---- |
| 语言 / 渲染 | 原生 JavaScript · Canvas 2D · CSS3，无任何前端框架 |
| 手势识别 | MediaPipe Vision（`assets/vendor/mediapipe/`，WASM 离线推理） |
| 音频 | HTML5 Audio + WebAudio 实时合成氛围音效 |
| 视频 | HTML5 Video + HTTP Range（支持 seek） |
| 服务器 | `serve.js` 零依赖 Node 静态服务器（MIME / Range / 探活 / 自动开浏览器） |

### 代码结构

```
js/
├─ main.js              主循环（rAF + dt 帧补偿）
├─ config.js            全局配置：构建版本、关卡资产、凝视参数、语音清单
├─ utils.js / audio.js  工具 & 音频管理（BGM / 配音 / 合成音型）
├─ city/                城景（视频城景驱动）
├─ game/                核心玩法
│  ├─ levels.js         四关定义：视频、目标轨迹（逐帧标定）、引导物
│  ├─ game.js           凝视命中 / 充能 / 场景状态机
│  ├─ hints.js          引导提示
│  ├─ save.js           进度存档（localStorage）
│  ├─ score.js          得分
│  └─ success.js        结算流程
├─ input/               输入驱动
│  ├─ hand_driver.js    MediaPipe 手部追踪驱动
│  ├─ mouse_driver.js   鼠标驱动
│  └─ input.js          统一输入层（双模式热切换）
└─ render/
   ├─ renderer.js       Canvas 渲染
   ├─ ui.js             全部 UI 界面（标题/选关/结算/转盘/弹窗）
   └─ effects.js        粒子特效（光爆 / 星屑 / 亮灯）
```

## ⚙️ 配置与自定义

- **全局参数**：`js/config.js` —— 凝视充能时长（`GAZE.FILL_SEC`）、判定容差、资产路径、语音清单（`VOICE_FILES`）。
- **换关卡视频**：替换 `assets/videos/*.mp4` 后，**必须**重新核对 `js/game/levels.js` 中每关 `target.path` 的轨迹坐标（目标是按视频逐帧标定的）。
- **换角色卡**：替换 `assets/images/cards/*.jpg`（建议 3:4 竖版），保持文件名与 `levels.js` 中 `card.image` 一致。
- **加配音**：把 mp3 放进 `assets/audio/`，在 `config.js` 对应字段登记文件名即可，未登记不请求。
- 详细素材规范见 [`assets/素材说明.txt`](assets/素材说明.txt)。
